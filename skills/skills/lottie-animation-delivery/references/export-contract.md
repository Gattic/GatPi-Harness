# Animation handoff contract

Record composition name, source file, exported file, duration, frames per second, width/height, loop policy, color, fonts, image assets, target renderer versions, interactive states and fallback.

A valid JSON document is not necessarily a valid Lottie asset. Confirm layer schema, referenced media, unsupported effects and target player behavior. Cross-check the first, middle and last frames and the last-to-first seam for loops. With dotLottie containers, validate ZIP membership, manifest paths and playback with an actual compatible player.

Creator MCP may be used **only** when available and explicitly connected. Never fabricate exported media when no renderer was run.

Source: https://github.com/LottieFiles/motion-design-skill
