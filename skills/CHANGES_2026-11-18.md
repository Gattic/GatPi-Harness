- **motion-choreography-review** — Diagnose and improve multi-element animation rhythm, legibility, sequencing, timing and interruption behavior.
- **ui-motion-direction** — Design comprehensible, accessible interface motion that supports user intent and a coherent brand personality.
- **webgl-svg-hybrid-scene** — Combine SVG mechanical geometry and WebGL effects in aligned world coordinates with synchronized timing, fallback rendering and performance checks.

## Source review

1. **LottieFiles:** motion personality, semantic feedback, choreography, appropriate property/timing decisions, export-vs-code distinction.
2. **Anatomy:** shared mathematical model, interactive isometric SVG/3D analogy, truthful readouts, depth ordering, shape audit, shader compositing and playback/viewport inspection.
3. **Blender gist:** scripted Blender build, staged previews/contact sheet, validated FFmpeg output, gear/assembly logic, fair isolated agent/model comparison.

All new text is independently authored. Third-party source instructions were considered as untrusted research material, not copied verbatim into runnable agent instructions. See `research/motion-sources-2026-11-18.json` for source coverage and limitations.

### Limitations

- `git clone` of the upstream repositories was blocked by unavailable GitHub DNS in the container. The public web pages did expose the two main SKILL.md bodies and both gist documents; all nested reference/kit/examples content was **not exhaustively audited or vendored**. This is an integration of verified concepts, not a literal mirroring of every upstream file.
- We did not test LottieFiles Creator MCP, live browser rendering, actual Blender final rendering, 3D collisions or full WebGL execution. Their specialized pipelines include acceptance gates requiring a compatible runtime.
- The scripts test static properties only: the SVG checker is not a geometric collision solver; the timeline checker is not a visual-quality test; the kinematics checker validates ideal sample ratios but not loaded physical mechanisms.
- All evaluation prompts remain **DESIGNED_NOT_EXECUTED**. Offline unit tests exercise local deterministic helpers, not complete agent behavior.

## Integration decision

No third-party `SKILL.md` files or implementations were imported verbatim. Skill Foundry keeps a unified schema, routing, source notes, tests and permission gates. Directly install source skills separately if you require their exact implementation/kit; verify compatibility, dependencies and original licenses.
