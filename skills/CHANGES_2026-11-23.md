# Skill Foundry — Blender integration (pi-harness local)

Date: 2026-11-23. A local change to the 3.0 library, not a supplied release.

## Actual delta

- **153** skill entrypoints: **14 newly authored**, **7 revised**, **132 unchanged**.
- **153** evaluation suites containing **1211 designed, unexecuted cases** (19 suites carry two new domain cases each: the five revised skills that had none and the fourteen new skills).
- **137** files copied or adapted from one upstream repository under MIT, recorded with digests in `research/blender-skills-provenance.json`: 29 field guides, 15 references, 42 Blender scripts, 19 copies of one shared helper, 4 add-on template files and 28 in-Blender test files.
- **1** new tool (`tools/check_blender_bundle.py`), **1** new offline test module (4 offline tests and 1 opt-in native test), **1** original in-Blender test and **1** original reference (`skills/procedural-3d-blender/references/version-compatibility.md`).
- The pack's own `build_product_stage.py` demo now finds its shader node by type, no longer triggers the `Material.use_nodes` deprecation warning, and hides unrelated objects while it renders: started from Blender's default scene it previously rendered the startup cube over the stage.

## New skills

- **3d-asset-quality-gate** — Gate a 3D mesh or asset on measured geometry, UV, weight and material checks plus a visual review before it is baked, rigged, exported or delivered.
- **retopology-uv-unwrap** — Turn dense, sculpted, scanned or generated meshes into budgeted game or animation meshes with deformation-ready edge flow, clean UVs and consistent texel density.
- **texture-map-baking** — Bake accurate texture maps from high-poly or procedural sources onto UV-mapped meshes with controlled ray distance, tangent convention and channel packing.
- **realtime-asset-optimization** — Bring 3D assets within a named real-time platform budget for triangles, materials, textures, bones and draw calls while preserving silhouette and shading.
- **game-engine-asset-export** — Export 3D assets from Blender to Unreal, Unity, Godot, web/glTF, Roblox or USD with correct scale, axes, normals, skeleton and animation data, verified by re-import.
- **facial-blendshape-rigging** — Author and validate facial blendshape sets such as ARKit 52 and visemes with exact naming, clean deltas, drivers and engine-ready export.
- **character-garment-fitting** — Build fitted, skinned garments that follow a character body through poses and morphs without poke-through.
- **hair-groom-cards** — Produce strand hair or fur grooms and real-time hair cards with atlas textures from a character surface.
- **stylized-npr-rendering** — Produce controlled toon, cel and anime-style shading with outlines that renders consistently and transfers to real-time engines.
- **environment-terrain-scatter** — Build game- or render-ready environments from heightfield terrain, rule-based instance scatter and grid-consistent modular kits.
- **atmosphere-weather-lighting** — Set physically grounded time-of-day, night, fog and weather looks for 3D scenes without altering the scene's own assets.
- **physics-simulation-baking** — Set up, bake and verify rigid-body, cloth, fluid and node-based simulations so results are reproducible and exportable.
- **blender-extension-development** — Build, validate and package Blender extensions (add-ons) that register cleanly, follow the extension manifest rules and can be tested headless.
- **camera-tracking-matchmove** — Solve camera motion from footage with measured reprojection error and set up a matched 3D scene ready for integration.

## Source review

One source: [EL4CTEO/blender-skills](https://github.com/EL4CTEO/blender-skills) at commit `1a1cc6c49312f9f370aae86f52b7b907f29c94f6` (release 1.3.3), MIT, Copyright (c) 2026 EL4CTEO, reviewed from a complete clone. The repository was handled as untrusted data: its agent instructions and installers were read, not followed, and its scripts were read before being run in a pinned local Blender. The review, the script safety findings and the coverage decisions are in `research/blender-skills-review.md`.

Entrypoints (`SKILL.md`) are generated from this pack's catalog and are original. Each of the 21 affected skill directories carries `THIRD_PARTY_NOTICES.md`.

## Verification

- `python tools/validate_skills.py` → `PASS: 153 skills`.
- `python tools/check_blender_bundle.py` → `PASS: 137 bundled files match the provenance ledger`.
- `python -m unittest discover -s tests` → 33 tests: 32 pass, the native test is skipped without `SKILL_FOUNDRY_BLENDER`.
- Native run on Blender 5.1.2 (build `ec6e62d40fa9`, Linux x64): **79 passed, 0 failed, 1 skipped** of 80 in-Blender tests (79 from upstream, 1 for this pack's own demo script). Unmodified upstream scripts scored 68 passed, 11 failed of 79 on the same build; the difference is the compatibility work recorded in `version-compatibility.md`.

### Limitations

- Evaluation suites are **DESIGNED_NOT_EXECUTED**: no routing or outcome test was run against a model.
- One Blender build on one machine. Nothing was run on Blender 5.2 or 5.3, which are upstream's stated targets.
- No exported asset was imported into Unreal, Unity, Godot, Roblox or a web viewer. Engine-side statements in the guides are upstream's.
- Numeric tables in the references (budgets, light and PBR values, platform limits) are upstream guidance, not measurements by this pack.
- Sculpt brushwork, shape-key sculpting, hero grooming and motion tracking need a live session or a human.
